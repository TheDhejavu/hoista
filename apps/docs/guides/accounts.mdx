An account connection lets Hoista reach one provider account, workspace or team. Hoista checks the credential, saves the connection and discovers the projects it can reach.

## Connect an account

In Desktop, open **Accounts** and pick a provider. Where the provider supports it, Hoista opens the provider's page in your browser and you approve access there. Otherwise, Hoista links to the provider's tokens page and you paste an API token. Hoista saves the credential in the OS credential store.

```bash
hoist accounts add
hoist accounts add railway
hoist accounts add cloudflare --name Personal
hoist accounts
```

In a terminal, `hoist accounts add` asks for anything you leave out, the token included, in a hidden prompt. Hoista finds the provider's account ID from the token; when the token reaches more than one account, it asks which, and scripts pass `--account` with the provider's account ID, team ID or organization slug. `--name` gives the account a name you will recognise in Hoista. The token's permissions limit what Hoista can do on that provider. See [providers](/providers/overview) for what Hoista supports on each one.

## Use a password manager

To pipe a token from a password manager, use `--token-stdin`:

```bash
YOUR_PASSWORD_MANAGER_COMMAND | hoist accounts add cloudflare --token-stdin
```

Never put a token in a command-line argument, an `echo` command, a chat or an MCP configuration.

## Check, rotate or disconnect

In **Accounts**, open an account's menu for **Check connection**, **Reconnect** or **Replace token**, and **Disconnect**. Reconnecting the same account updates its credential and keeps its projects.

```bash
hoist accounts check ACCOUNT
hoist accounts refresh ACCOUNT
hoist accounts rotate ACCOUNT
hoist accounts remove ACCOUNT
```

`ACCOUNT` is the account's name or Hoista's ID from `hoist accounts`, not the provider's own ID. `hoist accounts refresh` looks for new projects on an account now. `hoist accounts rotate` replaces the token; Hoista checks the new one with the provider before it saves it. It takes `--token-stdin` too.

Disconnecting removes the saved credential. It does not delete anything at the provider or stop the provider's billing.
