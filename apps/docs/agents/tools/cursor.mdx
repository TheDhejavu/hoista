title: "Cursor"
description: "Add Hoista as an MCP server in Cursor."
---

Cursor starts Hoista's MCP server itself, over stdio. You need Hoista on this computer: run `hoist doctor` to check.

## Add Hoista

Print the settings to add:

```bash
hoist mcp config --name Cursor
```

It prints something like this, with the full path to `hoist` on your computer:

```json
{
  "mcpServers": {
    "hoista": {
      "command": "/Users/you/.local/bin/hoist",
      "args": ["mcp", "--state-dir", "/Users/you/.hoista", "--name", "Cursor"]
    }
  }
}
```

Put the `hoista` entry in `~/.cursor/mcp.json` to use it in every project, or in `.cursor/mcp.json` inside one project. If the file already has an `mcpServers` object, add `hoista` inside it. The full path matters: Cursor doesn't always see the same `PATH` as your terminal.

Turn the server on from **Customize** in Cursor's sidebar if it isn't already.

## Approve it in Hoista

When Cursor starts Hoista, Hoista opens a page in your browser with a code. Check the code matches the one Cursor shows, choose **What it may do** and allow it. If the page doesn't open, allow it in **Agents** in the desktop app, or from a terminal:

```bash
hoist agents requests
hoist agents allow
```

Start with **View only** and widen it later in [Agent permissions](/agents/permissions).

## Check it works

Ask Cursor: "What projects do I have on Hoista?" It should list your projects. If it doesn't, see [If it doesn't connect](#if-it-doesnt-connect).

## Hoista on a remote

Cursor talks to Hoista on this computer. While a [remote](/guides/remote) is selected (`hoist remote use NAME`), `hoist mcp` won't start. To use the remote, add it to Cursor as an HTTP MCP server at its own address: `hoist mcp config` prints the remote's `/mcp` URL. Cursor then signs in with OAuth.

## If it doesn't connect

- Check the `command` path exists: run it in a terminal with `mcp --help`.
- Run `hoist doctor`.
- **To remove it:** delete the `hoista` entry, then revoke the agent in **Agents** or with `hoist agents revoke`.
