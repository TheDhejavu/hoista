Hoista is in public beta. Each beta is published on [GitHub releases](https://github.com/TheDhejavu/hoista/releases) as a pre-release, with signed downloads for the CLI, the engine and Desktop. The full history is in [CHANGELOG.md](https://github.com/TheDhejavu/hoista/blob/main/CHANGELOG.md).

<Update label="0.1.0 Beta 1" description="v0.1.0-beta.1 · 13 November 2026" tags={["Beta"]}>
  The first public beta of Hoista.

  **Install**

  ```bash
  curl -fsSL https://hoista.dev/install.sh | sh -s -- v0.1.0-beta.1
  ```

  Desktop for macOS and Linux, and the Windows CLI: [download v0.1.0-beta.1](https://github.com/TheDhejavu/hoista/releases/tag/v0.1.0-beta.1). More options: [Install](/getting-started/install).

  **Added**

  - `hoistd`, the engine, and `hoist`, the CLI.
  - Hoista Desktop for macOS (Apple Silicon and Intel) and Linux (AppImage and Debian package).
  - Providers: Cloudflare, Fly.io, Railway, Vercel, Neon, Supabase, Render, Resend, Runpod, Modal and GitHub, each connected with an API token.
  - [Import](/guides/import-apps) of what already runs on your providers.
  - [Deploys](/guides/deploy) with a plan you see first, live progress and rollback.
  - [Logs](/guides/logs), metrics and daily usage.
  - [Variables and domains](/guides/environment), and [environments](/guides/environments) such as production and staging.
  - [Billing](/guides/billing): what each provider has billed this period. Hoista never estimates cost.
  - An MCP server for [agents](/agents/connect), with [per-agent access](/agents/permissions) and a record of every call.
  - [Remotes](/guides/remote) on Railway, Fly.io or Docker.
  - [Backups](/guides/backups), an encrypted export and [webhooks](/guides/webhooks).
  - Signed releases: the installers check every download's Sigstore signature.

  **Known limitations**

  - Desktop is not yet signed with an Apple Developer ID or notarized. See [how to open it on macOS](/getting-started/install#desktop-app).
  - No Desktop app for Windows yet; the CLI and engine run on Windows.
  - Providers connect with API tokens only.
  - The beta update channel in Desktop's settings is not available yet. Install newer betas from their release page.

  Found a rough edge? [Report it on GitHub](https://github.com/TheDhejavu/hoista/issues).
</Update>
