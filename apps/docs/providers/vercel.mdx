Hoista finds the projects on a Vercel team and shows their production status, deployments, domains and build output. It can create a Vercel project from a GitHub repository and change a project's environment variables.

## Connect

In Desktop, open **Accounts**, choose Vercel, and paste a token:

1. Open [Tokens](https://vercel.com/account/settings/tokens): **Account Settings → Tokens → Create**. Name it Hoista.
2. Set the scope to your team, or to the one project it should reach.
3. Copy the token. Vercel shows it once.
4. Paste it into Hoista and pick the team.

</Frame>

From the CLI:

```bash
hoist accounts add vercel
```

It asks for the token in a hidden prompt and finds the team from it. In scripts, use `hoist accounts add vercel --name NAME --token-stdin`, and add `--account <team-id>` if the token reaches more than one team.

## What you can do

- Create a Vercel project linked to a GitHub repository. Vercel's GitHub app must be able to reach the repository.
- Read and change environment variables on the **Variables** tab.
- See build and deploy output on the **Logs** tab, and metrics on **Metrics**.
- Use the **Vercel** tab for the project's deployments, domains and settings, and for Vercel's own operations.
- See what Vercel has billed the team on **Billing**.
- Delete a project at Vercel after you confirm it by name.

## Bring in existing resources

Hoista looks for projects when you connect. In Desktop, add them as described in [Bring in an existing project](/guides/import-apps). From the CLI:

```bash
hoist import --list
hoist import <resource-id> --new my-app
```

Projects start in **watching** mode. Run `hoist projects manage my-app` when you want Hoista to make changes. To look again, run `hoist accounts refresh <account>` with the name or ID from `hoist accounts`.
