Hoista finds the web services, background workers, cron jobs, Postgres databases and Key Value stores in a Render workspace. It shows their settings, variables and metrics, and can create a new service or database.

## Connect

Render connects with an API key:

1. Open [API Keys](https://dashboard.render.com/u/settings#api-keys): **Account Settings → API Keys → Create API Key**. Name it Hoista.
2. Copy the key.
3. In Desktop, open **Accounts**, choose Render, paste the key and pick the workspace.

<Frame caption="Render’s API Keys page, captured November 2026. Personal details are blurred. If yours looks different, the names in the steps still match.">
  <img src="/assets/tokens/render-token.webp" alt="Render’s API Keys page" />
</Frame>

From the CLI:

```bash
hoist accounts add render
```

Hoista asks for the key in a hidden prompt. In scripts, use `hoist accounts add render --name NAME --token-stdin`, and add `--account <workspace-id>` if the token reaches more than one workspace.

## What you can do

- See a service's deploys, environment variables, custom domains, disk and settings on the **Render** tab.
- Set environment variables on the **Variables** tab.
- See metrics on **Metrics**.
- Create a service from a GitHub repository (a web service, static site, background worker or cron job), or a Postgres or Key Value database. Workers and cron jobs need Render's paid Starter plan.
- Use Render's own operations from the **Render** tab.
- Delete a service at Render after you confirm it by name.

Render's bill isn't shown on **Billing**. See it in the Render dashboard.

## Bring in existing resources

Hoista looks for services when you connect. In Desktop, add them as described in [Bring in an existing project](/guides/import-apps). From the CLI:

```bash
hoist import --list
hoist import <resource-id> --new my-app
```

Projects start in **watching** mode. Run `hoist projects manage my-app` when you want Hoista to make changes. To look again, run `hoist accounts refresh <account>` with the name or ID from `hoist accounts`.
