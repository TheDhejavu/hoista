Hoista finds the services and databases in the projects of a Railway workspace. It deploys services, redeploys or rolls back through Railway's own deployments, adds databases and buckets, and can run your [remote](/guides/remote).

## Connect

In Desktop, open **Accounts**, choose Railway, and paste a token:

1. Open [Tokens](https://railway.com/account/tokens): **Account Settings → Tokens → Create token**. Name it Hoista and pick your workspace. **No workspace** gives the token every workspace.
2. Copy the token and paste it into Hoista.
3. If Hoista asks for the workspace ID, press ⌘K in Railway and choose **Copy active workspace ID**.

<Frame caption="Railway’s New Token page, captured November 2026. Personal details are blurred. If yours looks different, the names in the steps still match.">

From the CLI:

```bash
hoist accounts add railway
```

It asks for the token in a hidden prompt and finds the workspace from it. In scripts, use `hoist accounts add railway --name NAME --token-stdin`, and add `--account <workspace-id>` if the token reaches more than one workspace.

## What you can do

- Deploy a service from a folder, a GitHub repository or a container image.
- Redeploy or roll back a service through Railway's deployments.
- Add a database or a bucket to a Railway project.
- Read and change variables on the **Variables** tab.
- See logs for the service's latest deployment, metrics, and daily usage with `hoist usage`.
- Use the **Railway** tab for Railway's own settings and operations.
- See what Railway has billed the workspace so far this period on **Billing**.
- Run your remote on Railway with `hoist remote create railway --account <account> --repo OWNER/NAME`. Until Hoista publishes a server image, `--repo` is needed; see [Set one up](/guides/remote#set-one-up).
- Delete a service or database at Railway after you confirm it by name.

## Bring in existing resources

Hoista looks for services when you connect. In Desktop, add them as described in [Bring in an existing project](/guides/import-apps). From the CLI:

```bash
hoist import --list
hoist import <resource-id> --new my-app
```

Projects start in **watching** mode. Run `hoist projects manage my-app` when you want Hoista to make changes. To look again, run `hoist accounts refresh <account>` with the name or ID from `hoist accounts`.
